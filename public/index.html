Interactive demonstration proving why blockchains cannot be altered without detection

Educational Sandbox

In traditional databases, an administrator or hacker with access can quietly change a vote. In this blockchain, every vote is part of a Merkle Tree, each block hash incorporates the Merkle Root and the Previous Block Hash. If an attacker modifies even a single character in a past block, the hash changes, the Merkle tree breaks, and the entire cryptographic chain breaks instantly!

🏛️ Object-Oriented Programming (OOP) Architecture

            
Mapping of C++ OOP concepts utilized throughout the codebase

          

          C++17 Standard
        

        

          


            

              
🎭

              
1. Abstraction

              
Pure virtual abstract base classes define strict interface contracts:

              
    
                
  • IVerifiable: Enforces virtual bool verify() const = 0;
    • 
                
  • ICryptoHashable: Enforces virtual std::string computeHash() const = 0;
    • 
                
  • AbstractBlock: Base contract enforcing consensus mining logic.
    • 
              

            


            

              
🔒

              
2. Encapsulation

              
Data hiding and state integrity protection:

              
    
                
  • Private internal vectors for chain, mempool, and transactions.
    • 
                
  • Public const-correct accessors (e.g. getHash(), getMerkleRoot()).
    • 
                
  • Invariants prevent arbitrary block or transaction state tampering.
    • 
              

            


            

              
🧬

              
3. Inheritance

              
Specialization and hierarchical domain modeling:

              
    
                
  • User base class → specialized into Voter and Candidate.
    • 
                
  • AbstractBlock → specialized into concrete Block.
    • 
                
  • Multiple inheritance: VoteTransaction : public IVerifiable, public ICryptoHashable.
    • 
              

            


            

              
🔄

              
4. Polymorphism

              
Runtime & Compile-time dynamic dispatch:

              
    
                
  • Runtime: Base class pointers (std::shared_ptr<Block>) calling overridden virtual methods.
    • 
                
  • Compile-time (Templates): MerkleTree<T> generic cryptographic audit tree for any hashable object.
    • 
              

            


            

              
➕

              
5. Operator Overloading

              
Natural C++ syntax for domain models:

              
    
                
  • operator<< for streaming formatted representations of blocks and transactions.
    • 
                
  • operator== and operator!= for comparing transaction identities.
    • 
              

            


            

              
🌐

              
6. Native Socket Web Server

              
POSIX socket HTTP/1.1 server implemented in C++:

              
    
                
  • Directly handles HTTP requests (GET, POST, OPTIONS).
    • 
                
  • Serves HTML, CSS, JavaScript files and JSON REST API without external frameworks.
    •
